# Ganesh Dussa — Portfolio

A modern, responsive portfolio website built with React, Material UI, and Framer Motion to showcase my experience, projects, and skills as a Software Engineer focused on backend systems, databases, and AI/LLM integration.

## 🚀 Features
- Responsive design — optimized for all screen sizes
- Dark / light mode toggle
- Signature animated "SQL query" hero, tying the design to a database/backend background
- Sections for experience, projects, skills, education, certifications, and recognition
- Smooth, purposeful motion via Framer Motion

## 🛠️ Tech Stack
- React 19 — component-based UI development
- Material UI (MUI) — themed component system
- Emotion — styling engine used by MUI
- Framer Motion — animation
- Vite — build tooling

## 📂 Installation
1. Clone the repository:
    ```bash
    git clone https://github.com/ganeshdussa/portfolio-website.git
    cd portfolio-website
    ```

2. Install dependencies:
    ```bash
    npm install
    ```

3. Start the development server:
    ```bash
    npm run dev
    ```

## 📝 Editing content
All resume content (name, summary, experience, projects, skills, education, certifications) lives in one place:
`src/data/resumeData.js` — edit that file to update anything shown on the site.

## 🚢 Deploy
This project is set up for GitHub Pages via `gh-pages`:
```bash
npm run deploy
```
Update the `base` path in `vite.config.js` and the homepage/repo URL if your repository name differs from `portfolio-website`.
